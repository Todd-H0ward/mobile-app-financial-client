ХРАНИТЕЛЬ — добрый ИИ на потолочном кронштейне
================================================

Hranitel_kind_AI.glb — модель (glTF 2.0 binary): Blender, Unity, Unreal, Godot, three.js.
  Масштаб: 1 единица = 1 м. Верх: +Y. Экран смотрит в +Z.
  Потолочная пластина на высоте ~5.6 м, телевизор висит на ~2.6 м.
  Кусок потолка (панель со световыми полосами) входит в файл — его можно удалить.

Анимации (зациклены):
  Idle_Pokoy    8 с — покачивается, осматривается
  Talk_Rech     4 с — говорит: кивает, покачивает «головой»
  Joy_Radost    3 с — раскачивается на кронштейне, виляет
  Sleep_Son     8 с — обвис, клюёт носом

Цепочка узлов кронштейна (для своих анимаций / IK):
  Keeper → MountYaw (поворот у потолка) → Shoulder → Elbow → WristComp
        → HeadYaw (поворот телевизора) → HeadTilt (кивок и наклон) → Head
  WristComp гасит наклон руки, чтобы телевизор висел ровно:
  его поворот по X = −(Shoulder.x + Elbow.x). Если анимируете руку сами — держите это правило.
  Screen — меш экрана (замените emissive-текстуру, чтобы сменить выражение лица).

Материалы: Case, Trim, Metal, Rubber, Ceiling, Glow (огоньки, полосы), Screen.

textures/screen_*.png — кадры экрана для каждого режима (idle, talk, joy, sleep), 1024×768.
  В движке подставляйте их в emissive-карту материала Screen при смене анимации.

Не входит в файл (формат glTF это не поддерживает): живой шейдер экрана,
моргание и слежение глаз, печать текста, сердечки и «Z», свечение вокруг экрана
и пятно света на полу — всё это есть в интерактивной версии на холсте.
