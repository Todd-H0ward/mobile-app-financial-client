# content

Учебный контент, отделённый от кода — требования 2.5.14 и 3.2.
Правила и состав файлов: [docs/content.md](../docs/content.md).

Новая цель накопления, задание или позиция каталога добавляется строкой в JSON,
без правки `.tsx`. Схема каждого файла проверяется тестами рядом с кодом,
который его читает: битый JSON не должен доезжать до устройства.

| Файл | Что описывает | Требование |
| --- | --- | --- |
| `goals.json` | Цели накопления: id, название, цена | 2.5.7 |
| `tasks.json` | Задания: тема, тип механики, тексты, сложность | 2.5.8, 2.5.14 |
| `lessons.json` | Уроки на ячейках арены: теория и проверочный вопрос | 2.5.14 |
