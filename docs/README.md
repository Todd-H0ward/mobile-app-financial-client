# Документация «Лапка»

Набор документов под требования ТЗ. Читать в этом порядке: сначала что мы
делаем и в каком порядке, потом как устроены механики, потом как это
проверяется и сдаётся.

## Статус проекта

**Волна 0, начало.** Реализована дизайн-система (`src/shared/ui`, 23 компонента)
и экран UI-кита. Игровых сущностей — экономики, периода, питомца, заданий —
в коде ещё нет: слои `entities/`, `features/`, `widgets/`, `_app/` не созданы.

Всё, что описано ниже, — это **спецификация, а не отчёт о готовом**. Реальные
статусы по каждому пункту ТЗ ведутся в
[requirements-matrix.md](./requirements-matrix.md); она и есть источник правды
для промежуточной сдачи и для защиты.
