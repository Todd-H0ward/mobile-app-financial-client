# Документация «Лапка»

Набор документов под требования ТЗ. Читать в этом порядке: сначала что мы
делаем и в каком порядке, потом как устроены механики, потом как это
проверяется и сдаётся.

## Статус проекта

**Демо-цикл собран.** Слои FSD на месте (`entities` / `features` / `widgets` /
`screens` / `_app`). Игра — подъём робособаки из ямы; старый концепт питомца
в доме (онбординг, создание и рост питомца, отопление) удалён. Сейчас проходит:
гостевой профиль → сцена-яма → план → магазин / задания / копилка → итоги
периода → демо за барьером. Знакомство внутри игры ещё предстоит сделать.

Концепт игры — в [concept.md](./concept.md), требования сдачи — в
[`output/planning/tz-finni-brief.md`](../output/planning/tz-finni-brief.md)
(не удалять). Живые статусы по пунктам ТЗ — в
[requirements-matrix.md](./requirements-matrix.md); карта кода — в
[architecture.md](./architecture.md); правила для агентов — в
[AGENTS.md](../AGENTS.md).
