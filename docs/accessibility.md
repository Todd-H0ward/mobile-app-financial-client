# Доступность

Требование 3.6, проверяемое. Четыре правила, каждое — свойство дизайн-системы,
а не забота отдельного экрана.

## 48dp — минимальная цель нажатия

`HIT_SLOP_SIZE = 48` в `shared/constants/theme.ts`.

- Кнопки размера `l` и `m` проходят по высоте сами (56 и 48).
- Размер `s` — 40, поэтому ему **обязателен** `hitSlop`.
- Любой самодельный `Pressable` мельче 48dp получает `hitSlop`, а не увеличение
  визуального размера: макет не должен страдать ради зоны нажатия.

Проверка: включить в Android «Показывать границы элементов» и убедиться, что ни
одна цель не меньше 48dp.

## 16sp — нижняя граница для содержательного текста

Шкала в `shared/ui/text.tsx`:

| Пресет | Размер | Можно использовать для |
| --- | --- | --- |
| `body`, `bodyBold` | 16 | основной текст — **пол для содержания** |
| `small`, `smallBold` | 13 | подписи, вторичные пояснения |
| `label` | 10 | только подписи навигации и иконок |

13 и 10 — не для содержания. Если текст несёт смысл, который нельзя пропустить,
он 16 и больше.

Шрифт не масштабируется системной настройкой размера по умолчанию — это нужно
проверить на устройстве и при необходимости разрешить `allowFontScaling` там,
где вёрстка выдерживает.

## Цвет — не единственный носитель смысла

Заложено в кит:

| Смысл | Носитель кроме цвета |
| --- | --- |
| Обязательное / необязательное | форма значка: круг и ромб (`Shape`), плюс текст категории |
| Низкий уровень шкалы | `tone="low"` добавляет рамку и более тёмную подпись, цвет остаётся тёплым |
| Выбранный элемент | рамка 2.5px, а не только заливка |
| Выполненное | зачёркнутый заголовок, а не только приглушённый цвет |
| Перерасход в итогах | знак `+` / `−` и текст, см. [budget.md](./budget.md#экран-итогов-план-vs-факт) |

**Никакого тревожного красного.** Низкая шкала сохраняет тёплый цвет; беспокойство
выражает реплика питомца, а не палитра. Это одновременно и 3.6, и запрет 3.5 на
пугающие визуальные реакции.

## Отключаемые звук и анимации

Оба переключателя — в разделе для взрослого ([parents.md](./parents.md)).

- **Звук** — глобальный флаг; при выключении ни один звук не воспроизводится.
- **Анимации** — при выключении Reanimated-анимации заменяются мгновенным
  переходом. Приложение обязано оставаться полностью работоспособным: анимация
  нигде не является единственным способом узнать, что что-то произошло.

Флаг анимаций читает и системную настройку «Уменьшить движение», если она
включена, — тогда переключатель по умолчанию выключен.

## Чек-лист перед сдачей

- [ ] Ни одной цели нажатия меньше 48dp.
- [ ] Ни одного содержательного текста меньше 16sp.
- [ ] Каждое состояние читается на чёрно-белом скриншоте.
- [ ] Звук отключается и остаётся отключённым после перезапуска.
- [ ] Анимации отключаются, приложение проходимо целиком.
- [ ] Нет тупиковых экранов: с любого экрана есть выход назад.
