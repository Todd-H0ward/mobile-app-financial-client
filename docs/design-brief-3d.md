# Лимиты 3D для дизайнера (из ТЗ + стек)

Источник ограничений: **п. 3.7** — устройство **от 3 ГБ RAM**, холодный старт
**≤ 5 с**, отклик **≤ 1 с**. Стек: Expo + `three` на `expo-gl`, цикл рендера на
**JS-потоке** (тяжелее нативного Unity/Unreal) → бюджеты ниже «обычного»
mobile WebGL.

Ниже — **максимумы**, которые можно отдавать артисту. Не путать с текущей
облегчённой сценой (~5k tris без текстур): это потолок, а не «как сейчас».

---

## Список для передачи дизайнеру

### Полигоны (треугольники на экране за кадр)

| | Значение |
| --- | --- |
| **Рекомендуемый целевой бюджет** | **≤ 20 000** tris |
| **Рабочий максимум** | **≤ 30 000** tris |
| **Жёсткий потолок (нельзя выше)** | **50 000** tris |

Пояснение: на 3 ГБ при рендере из JS упираемся не в память вершин, а в стабильные
30–60 FPS при свайпе камеры и отклик ≤ 1 с. Выше 30k — только после замера на
слабом Android; выше 50k для этого стека неприемлемо.

Повторяющиеся объекты — **клоны одной сетки** (не уникальный меш на каждый
клон). Иначе draw call’ы съедят бюджет раньше полигонов.

---

### Draw call’ы (уникальные пары mesh+material за кадр)

| | Значение |
| --- | --- |
| **Цель** | **≤ 25** |
| **Максимум** | **≤ 40** |
| **Потолок** | **50** |

Как укладываться: атласы + merge одинаковых материалов, мало уникальных
материалов, инстансы/клоны.

---

### Текстуры

| | Значение |
| --- | --- |
| **Суммарная видеопамять текстур (GPU, с mip)** | **≤ 24 МБ** цель, **≤ 32 МБ** потолок |
| **Макс. сторона одной текстуры** | **1024 px** (рекомендуется), **2048 px** — только **один** атлас на всю сцену, если без него нельзя |
| **Формат сдачи** | PNG или WebP, степень 2 (512 / 1024 / 2048) |
| **Число атласов / карт albedo** | **1–3** всего на сцену; идеал — **1 общий атлас** |
| **Набор карт на меш (1-й этап)** | только **albedo** (+ alpha при необходимости) |
| **Normal / roughness / metalness / AO** | **не в бюджете 1-го этапа** (съедают память ×2–4) |
| **Вес файлов текстур в приложении (на диске)** | **≤ 3 МБ** цель, **≤ 5 МБ** потолок — иначе риск старта > 5 с на слабом CPU |
| **UV** | один набор UV под атлас; padding **4–8 px** между островами; без критичного overlapping на видимых гранях |

Примеры укладки в 24 МБ GPU (RGBA8 + mip ≈ ×1.33):

- **4 × 1024×1024** ≈ 21 МБ  
- **1 × 2048×2048** ≈ 21 МБ (весь бюджет в один атлас)  
- **1 × 1024 + 4 × 512** ≈ 8 МБ (с запасом под мебель позже)

**Нельзя:** набор из нескольких 2048, 4096, отдельные 2k на каждый предмет.

---

### Материалы и свет

| | Значение |
| --- | --- |
| **Уникальных материалов** | **≤ 8** цель, **≤ 12** максимум |
| **Шейдер** | простой (цвет / albedo), без стекла/прозрачности с сложным sorting на 1-м этапе |
| **Realtime-тени, SSR, отражения, HDRI** | **нет** |
| **Свет** | 1 key + 1 fill + ambient (как сейчас) |

---

### Анимация и структура сцены

| | Значение |
| --- | --- |
| **Скелет / blend shapes / клипы в FBX дома** | **нет** |
| **Движение в модели** | только **ярусы/ступени по Y** (плоские уровни) |
| **Число ярусов** | до **5–8** плоских уровней с **одинаковым** шагом по высоте |
| **Спираль/терраса без ярусов** | не использовать как «ступени» — код поднимает только плоские ярусы |

Три сектора одной модели (улица / гостиная / кухня), переход = поворот сцены.

---

### Размер геометрии в поставке

| | Значение |
| --- | --- |
| **Экспорт** | бинарный FBX |
| **После конверта в JSON (геометрия)** | ориентир **≤ 1.5 МБ**, потолок **≤ 3 МБ** |
| **Единицы / масштаб мира** | не менять без согласования (сейчас шаг яруса = 40) |

---

### Память и ТЗ (как считали)

На устройстве **3 ГБ** под приложение остаётся мало после ОС + React Native.

| Статья | Бюджет |
| --- | --- |
| Геометрия сцены в GPU | ~2–5 МБ при 20–50k tris |
| Текстуры в GPU | **24–32 МБ** |
| Запас под UI, питомца, RN, пики | обязателен |
| **Итого 3D-ассеты сцены** | держать **≲ 40 МБ** GPU |

Старт ≤ 5 с: тяжёлые текстуры нельзя декодировать пачкой на первом кадре —
отсюда потолок **~5 МБ** файлов на диске и предпочтение **1024** над пачкой
**2048**.

Отклик ≤ 1 с / свайп камеры: режет **draw calls** и **fill rate** (большие
текстуры + overdraw) сильнее, чем «ещё 5k полигонов».

## Коротко одной карточкой

```
Полигоны:     цель ≤ 20 000  |  макс 30 000  |  потолок 50 000
Draw calls:   цель ≤ 25      |  макс 40      |  потолок 50
Текстуры GPU: ≤ 24 МБ (потолок 32 МБ)
Размер тексты: ≤ 1024 (один атлас до 2048)
Атласов:      1–3 (лучше 1)
Файлы текстур: ≤ 3–5 МБ на диске
Материалы:    ≤ 8–12, только albedo
PBR/тени/SSR: нет
Анимация FBX: нет (только подъём ярусов)
```

Приёмка: прогон на Android **от 3 ГБ**, релизная сборка — сцена крутится
без фризов, старт приложения ≤ 5 с, касания ≤ 1 с.
