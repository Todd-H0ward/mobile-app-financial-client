# Лицензии

Все изображения, шрифты, звуки и библиотеки должны иметь право на использование
в составе прототипа. Это обязательный пункт пакета документации и проверяемое
требование — отсутствие реестра стоит баллов по 8.2.

## Правило

Ассет попадает в репозиторий **только вместе со строкой в таблице ниже**.
Строка заполняется в том же PR, что и файл. Пустая колонка «Лицензия» — повод
не мержить.

## Шрифты

Берём заведомо свободные с кириллицей.

| Шрифт | Лицензия | Кириллица | Статус |
| --- | --- | --- | --- |
| Inter | SIL OFL 1.1 | да | кандидат |
| Nunito | SIL OFL 1.1 | да | кандидат |
| Onest | SIL OFL 1.1 | да | кандидат |

Сейчас типографика идёт на системном шрифте (`FONTS` в
`shared/constants/theme.ts`). Выбрать один и забандлить — задача волны 0.

независимо от лицензии; они удаляются вместе с `AnimatedIcon` и `SplashOverlay`
или заменяются своим артом.

## Звуки

Звуков пока нет. При добавлении: источник, лицензия, и обязательно —
возможность **отключить звук** (требование 3.6, см.
[accessibility.md](./accessibility.md)).

## Библиотеки

Все текущие зависимости — MIT или Apache-2.0. Проверка одной командой:

```bash
npx license-checker --production --summary
```

Результат прикладывается к пакету сдачи. Зависимость с копилефт-лицензией
(GPL, AGPL) в прототип не берём.

| Библиотека | Лицензия |
| --- | --- |
| expo, expo-router и модули | MIT |
| react, react-native | MIT |
| react-native-reanimated, gesture-handler, screens, safe-area-context | MIT |
| zustand | MIT |
| i18next, react-i18next | MIT |
| sonner-native | MIT |
| biome, typescript, vitest | MIT / Apache-2.0 |

Таблицу обновлять при каждом добавлении зависимости; сверка с выводом
`license-checker` — часть шага 32 в [roadmap.md](./roadmap.md).

## Уточнение инвентаризации — 25.09.2026

Предыдущие строки этой страницы относятся к раннему прототипу и не являются
подтверждением прав на текущую поставку. Проверка установленного графа npm
выполнена `node scripts/audit-runtime-dependencies.mjs`: 583 пакета, все найдены,
у всех есть декларация лицензии. Машиночитаемый реестр:
`build/runtime-dependencies.json`. Это граф зависимостей из dependencies,
включая инструменты Metro/Babel, а не только код, попавший в JS bundle.
Нативные Maven-зависимости этим отчётом не покрыты.

Утверждение выше «все MIT или Apache-2.0» для нынешнего графа неверно:
есть также ISC, BSD, MPL-2.0, CC-BY-4.0 и другие декларации. В отчёте сохранены
исходные SPDX-выражения, версии, репозитории и имена файлов лицензий.

| Текущий арт | Что установлено по репозиторию |
| --- | --- |
| `assets/robot-dog/robot-dog.glb`, семь наборов текстур | Модель и текстуры присутствуют; отдельная лицензия/авторство в этой поставке не найдены |
| `assets/scene/сцена.fbx`, `scene.json` | Исходник и производная сцена присутствуют; сведения о правах не найдены |
| `assets/scene/watchers/*` | README описывают модель и разрешённые технические изменения; полноценного указания авторства/лицензии не содержат |
| Иконки и splash из `app.json` | Оригинальный SVG assets/branding/finni.svg и производные PNG созданы в рамках проекта |

Авторство пользовательских 3D-моделей нельзя определить по форме файла.
До публичной передачи пакета необходимо дополнить эту таблицу фактическими
источниками или сведениями о собственном авторстве команды.

Короткие WAV-эффекты синтезированы скриптом `scripts/generate-game-audio.py`,
без сторонних записей и сэмплов. Модули робопса созданы кодом геометрии
`widgets/room-scene/lib/robot-modules`; права на исходную GLB это не определяет.

После добавления expo-audio повторный локальный аудит: 584 npm-пакета,
не найденных пакетов и отсутствующих деклараций лицензий — 0.
