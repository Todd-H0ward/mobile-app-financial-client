# Производительность

Требование 3.7, проверяемое на устройстве: **старт ≤ 5 секунд, отклик ≤ 1
секунда** на устройстве от 3 ГБ оперативной памяти.

## Риск стека

React Native с холодным стартом на слабом Android — риск ровно по этому пункту.
Стек по ТЗ свободный; если в команде нет опыта оптимизации RN, Kotlin + Compose
безопаснее. Решение принимается осознанно и один раз — переезд на волне 2 не
состоится.

Раз выбран RN, меры ниже обязательны, а не «если останется время».

## Старт ≤ 5 секунд

| Мера | Почему |
| --- | --- |
| Hermes включён | байткод вместо парсинга JS при запуске |
| Релизная сборка для замеров | dev-сборка стартует в разы дольше и меряет не то |
| Минимум работы до первого кадра | чтение профиля асинхронно, экран показывает заглушку, а не ждёт |
| Ничего тяжёлого в модульной области | `Dimensions.get()` и подобное на старте — норма, парсинг JSON контента — нет |
| Контент грузится по требованию | `content/*.json` нужен на своём экране, а не при запуске |
| Шрифт один | каждый забандленный шрифт — это байты и кадр задержки |

**React Compiler выключен** (`app.json → experiments.reactCompiler: false`) — он
ломает worklets Reanimated в этом проекте, см. AGENTS.md. Это не про скорость, но
включение ради оптимизации уронит приложение.

## Отклик ≤ 1 секунда

| Мера | Почему |
| --- | --- |
| Анимации на UI-потоке | Reanimated shared values — JS-поток не участвует в кадре |
| Никаких пересчётов в worklet | worklet вызывает только worklet, см. AGENTS.md |
| Сохранение не блокирует ввод | запись профиля асинхронна, экран не ждёт её |
| Списки виртуализируются | каталог и история — `FlatList`, не `map` в `ScrollView` |
| Не больше одного анимированного питомца на экране | три анимированных аватара — то, что заикается |

## Как меряется

Замеры на **физическом устройстве** от 3 ГБ, в **релизной** сборке, после
холодного запуска (приложение выгружено из памяти).

```bash
# Холодный старт, Android
adb shell am force-stop <package>
adb shell am start -W -n <package>/.MainActivity
# TotalTime в выводе — это и есть время старта
```

Отклик меряется секундомером по сценарию: нажатие «Подтвердить план» →
появление главного экрана; нажатие на позицию каталога → появление
подтверждения.

Результаты прикладываются к пакету сдачи (шаг 36 в
[roadmap.md](./roadmap.md#волна-3--сдача)).

## Чек-лист перед сдачей

- [ ] Отклик на каждое действие обязательного сценария ≤ 1 с.
- [ ] Нет тупиковых экранов.
- [ ] Приложение проходимо целиком без интернета — в авиарежиме.
