# Приватность и работа без сети

Приложение для детей, поэтому самый безопасный дизайн — тот, где защищать
нечего: **ни аккаунта, ни аналитики, ни сетевых вызовов в игровом цикле.**

## Основной цикл работает без интернета

Это требование, а не приятная особенность. Обязательный сценарий целиком —
онбординг, создание питомца, план бюджета, задания, покупки, накопления, итоги,
демо-режим — проходится в авиарежиме.

Отсюда следует архитектурное ограничение: **никакого LLM-чата и никакой
серверной генерации контента.** Формально ИИ не запрещён, но он не входит в
минимум, потребовал бы обоснования задачи, данных и контроля корректности
результата, и ломал бы офлайн-требование. Реплики питомца и диалоги с выбором
ответа — сценарные, см. [pet.md](./pet.md#чего-здесь-нет).

Проверка перед сдачей — пункт чек-листа в
[performance.md](./performance.md#чек-лист-перед-сдачей): пройти обязательный
сценарий с выключенной сетью.

## Что хранится и где

| Данные | Где | Покидают устройство |
| --- | --- | --- |
| Игровое имя, питомец, его внешность и черты | локальная база `expo-sqlite`, ключ `@app:user` | нет |
| Монеты, история операций (100 записей) | там же | нет |
| Копилка и цели | там же | нет |
| План и факт по периодам, история периодов | там же | нет |
| Дом: температура, утепления, мебель | там же | нет |
| Настройки взрослого, флаг демо-режима | там же | нет |

Свободного ввода в приложении два поля: игровое имя и имя питомца. Ни почты, ни
телефона, ни фото, ни геопозиции, ни контактов, ни рекламного идентификатора.

Игровое имя — это игровое имя. В интерфейсе оно нигде не называется настоящим
именем и никуда не передаётся.

## Чек-лист

- [x] Нет регистрации и аккаунта.
- [x] Нет аналитики и SDK сбора данных.
- [x] Нет сторонней рекламы.
- [x] Нет сетевых запросов с данными о ребёнке. `EXPO_PUBLIC_API_URL` в
      релизной сборке не задан, игровой цикл его не вызывает.
- [x] Отчёт для взрослого считается на устройстве из локального сейва.
- [x] Барьер для взрослых описан как барьер, а не как защита данных.
- [ ] Политика конфиденциальности опубликована по публичному адресу (нужна для
      карточки RuStore).
- [ ] Возрастная маркировка обоснована: **6+** — нет насилия, нет общения с
      незнакомцами, нет пользовательского контента, нет покупок.
- [ ] Анкета магазина заполнена как «данные не собираются».

## 152-ФЗ

Закон применяется к обработке персональных данных. Приложение их не обрабатывает:

- [x] Персональные данные не собираются — уведомлять Роскомнадзор не о чем.
- [x] Трансграничной передачи нет, потому что передачи нет вообще.
- [x] Требование о локализации (ст. 18 ч. 5) неприменимо: базы данных граждан РФ
      не существует.
- [ ] Если появится синхронизация или облачный бэкап — этот раздел перестаёт быть
      верным, и такой функции нужны уведомление, согласие и хранение в РФ **до**
      релиза.

## Что изменило бы картину

Любое из этого делает приложение оператором данных и требует бумаг **до**
релиза:

- аккаунты или семейная синхронизация;
- облачный бэкап сейва;
- аналитика, remote config или крашрепортинг с идентификаторами;
- настоящий чат, отправка голоса куда-либо, пользовательский контент;
- **обращение к внешней языковой модели** — отдельная причина, по которой
  LLM-чата в проекте нет.
