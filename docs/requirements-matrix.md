# Матрица соответствия требованиям

Живой документ. Обновляется тем, кто закрывает пункт, **в том же PR**, а не
перед сдачей. На защите это половина ответов экспертам: на любой вопрос
«а где у вас 2.5.5» отвечает строка таблицы.

Статусы: **готово** / **в работе** / **не начато**.
Пустая ячейка «Тест» означает, что проверка ручная и описана в тест-кейсе.

## Как заполнять

Пункт закрыт, когда одновременно верно:

1. названы экран **и** модуль — не «где-то в экономике»;
2. есть автотест либо номер ручного тест-кейса;
3. пункт проходится на физическом устройстве в демо-режиме.

Строка со статусом «готово» без ссылки на модуль — это не «готово».

## Единое сохранение — 25.09.2026

- UserSave v9 объединяет деньги, платформу, игровые сессии, пройденные уроки
  и аркадные рекорды. Демо, сброс и удаление применяются ко всему профилю.
